# Empty-record audit of 21 gated tools

Eight of the 21 candidates in #1468 accepted empty evidence on the paths below at `8e8551b3`. Each of the eight has a control that failed before the fix. One additional tool now labels an empty listing. The original census selected files by a failure-list pattern and a basename in a Makefile or workflow. This fraction describes that selection only. In particular, the timing CLI reproduction establishes no change in a running CI job.

The product questions are whether the mono reference actually exercised its declared settings, whether the 808 ensemble comparison had samples, and whether the FPGA player has evidence for its builds. No sound was tuned or image rebuilt in this audit. The build and plugin fixtures replay evidence or substitute the external process. Their results apply to the consumer named in each row.

Run commands from the repository root with the Python packages in `spec/trial-environment.json`. Test names in the table are pytest selectors. **Replay** refers to `python -m pytest -qs tools/probes/tier2_empty_records.py`, which supplies the more involved fixtures. Numbers in parentheses are tool exit codes. For a library, the table gives its returned result or exception. A successful pytest replay exits 0 after asserting both outcomes.
