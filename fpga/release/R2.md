## Open before a freeze or a build

1. **`verify_voice --set full` fails, and it fails on R1 too (#354).**
   - It fails in `extremes` and in an `audition` sequence.
   - R1's published `voice_dp.v` fails the same subset with the same counts.
   - R2's RTL output equals R1's in every value column. Only the strobe cycle moves, 2–21 cycles earlier.
   - So R2 inherits the gap and does not cause it. It still blocks a claim of full component equivalence.
2. **The 2x rectangle decimator's headroom.** At MIDI ≥ 108 it reaches the rail with 0.85. The sound owner is sizing it against 0.80, and the value may change RTL or model constants.
3. **UART path in R2's configuration.** `verify_deadline --scenario arty-uart` refuses PULSE2X=1, so the UART bench needs extending for R2's configuration.
4. **#315 XDC repair**, to go into the same reviewed image if it is ready.
5. **Named image selection (#323).** The host has no `--image r2` yet.
6. **Release checks for a second image.** On this branch `voice_dp.v` differs from R1's freeze. `r1_candidate.check()` therefore reports STALE by design, and R0's T-RELEASE-BOUND (bound through `rev14-clean/verification.json`) does too. The branch cannot merge to `main` until the release checks bind R1's frozen sources from git rather than from the working tree, or R2 supersedes them by review.
7. **The Vivado build**, under #205, only after items 1–5. Timing, I/O, DSP and warnings must be derived from that image.
